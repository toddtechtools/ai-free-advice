# AI Free Advice

## The Number Is the Run Order

I wrote this free guide for teams that hand deployment scripts from one person or AI session to the next. It includes a Bash runner and rules you can paste into `AGENTS.md`.

[Get the offline HTML guide](docs/01-the-number-is-the-run-order-v1.3.html)

Try it on one folder. If a teammate still has to ask what runs next or how to verify the result, I’d like to see the example.

[Open a GitHub issue](https://github.com/toddtechtools/ai-free-advice/issues/new) with a sanitized file listing and the step that caused confusion. That gives us something concrete to improve for the next team.
